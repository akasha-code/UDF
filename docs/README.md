## Authority

The numbered documents in [`wiki/`](../wiki/README.md) define the canonical public framework. The material here explains how to navigate and apply those definitions. If guidance conflicts with the canonical reference, the framework reference prevails.

Commercial manuscripts, complete worked cases, professional training material, and proprietary product implementations are maintained separately and are not part of this repository's Apache 2.0 distribution.
